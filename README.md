# 納品書管理（スマホ撮影 → 日付・正味を自動読み取り → 現場別Excel集計・写真台帳）

納品書・送り状をスマホで撮影すると、**端末の中で文字を読み取って「日付」と「正味(kg)」を自動入力**します。
APIキー・月額費用は不要で、通信せずに動きます（初回のみ文字認識データ約30MBをダウンロード）。
確認して保存すると現場ごとに集計され、次の3つを出力できます。

| 出力 | 中身 |
|---|---|
| **Excel集計表** | ①現場別・材料別・月別の集計 ②「材料入荷・使用量一覧表」（現在の様式と同じ：1台目〜15台目、台数/搬入量/使用量の日計・累計、残量）③全伝票の明細 |
| **写真台帳PDF** | A4横に3枚ずつ、日付順に並べた伝票写真（今のテープ貼り台帳の置き換え） |
| **写真ZIP＋Excel** | `現場名/年月/日付_材料_重量.jpg` の名前で整理した写真と、Excelをまとめたもの |

## 使い方

1. **設定** タブで現場（工事件名）を登録する。
2. 上部の「現場」で今日の現場を選び、**撮影** タブで「納品書を撮影」。続けて何枚でも撮れます。
3. 数秒で日付と正味が自動入力されます。**写真の日付欄・正味欄を拡大した画像**が入力欄のそばに出るので、見比べて「保存」。
   - 緑「検算済み」：全重−風袋＝正味 が合った（住友の納品書）
   - 黄色「写真で確認」：正味欄だけ読めた、または計算が合わない。候補ボタンから選び直せます
   - 読めなかった時は、過去によく使った重さ（例 8,000 / 4,000）が候補ボタンに出ます
   - 日付を読み取れなかった時は撮影日が入り、黄色で表示されます
   - 材料もその現場でよく使うものがボタンで出ます
4. **集計・出力** タブで材料ごとの入荷状況を確認し、「使用量」を入力できます（Excelの使用量欄に入ります）。
5. 必要なときに Excel / 写真台帳PDF / 写真ZIP を出力。「共有」でメール・LINE・Googleドライブへ直接送れます。

スマホではブラウザのメニューから **「ホーム画面に追加」** してアプリとして使ってください（データが消えにくくなります）。

## 自動読み取りの精度（添付サンプルで検証）

| 伝票 | 結果 |
|---|---|
| 項目 | UBE三菱セメント 送り状 | 住友大阪セメント 納品書 |
|---|---|---|
| 正味 | 68枚すべて正解 | 12枚中11枚正解（10枚は全重−風袋で検算済み）。残り1枚は「計算が合わない」と警告し、正しい値を候補ボタンに表示 |
| 日付 | 68枚中65枚正解、3枚は読めず撮影日＋黄色表示（誤った日付の入力は0件） | 12枚すべて正解 |

スキャン画像41+6枚と、それをスマホ撮影風に加工した画像（傾き・影・ぼけ）27+6枚で試した結果です。実際のスマホ写真では条件により下がることがあるので、**保存前に拡大画像と見比べる運用**にしてください。
読み取りは PaddleOCR（PP-OCRv4）を端末内で動かしています。点で印字する文字（ドット印字）は、画像を少し縮小・ぼかしてから読むことで読めるようにしています。

## 導入手順（Netlify・無料）

このリポジトリは Netlify にそのままデプロイできます（`netlify.toml` 設定済み。環境変数の設定は不要）。
公開されたURLをスマホで開き、「ホーム画面に追加」すれば使えます。

### 手元で動かす場合

```bash
npm install
npx netlify dev   # http://localhost:8888
```

### （任意）有料のAI読み取り

正味以外（日付・品種・工事名など）も自動で読みたくなった場合は、Claude API による読み取りを追加で使えます（1枚5〜10円程度）。
Netlify の環境変数に `ANTHROPIC_API_KEY`（必須）と `APP_PASSCODE`（推奨）を設定し、アプリの「設定 → 有料のAI読み取りを使う」をオンにしてください。
任意で `SLIP_AI_MODEL`（既定 `claude-opus-5`）、`SLIP_AI_EFFORT`（既定 `medium`）も変えられます。オフのままなら費用は一切かかりません。

## 注意点（必ずお読みください）

- **自動読み取りは100%ではありません。** 数字1桁の誤りが請求に直結するため、保存前に正味(kg)を拡大画像と見比べてください。確認が必要なものは黄色で表示されます。
- **データはその端末のブラウザ内に保存されます。** 機種変更・ブラウザのデータ削除・（iPhoneで長期間開かない場合の）自動削除で消えることがあります。「設定」→「バックアップを保存」を週1回程度行い、Googleドライブ等に置いてください。別の端末へは「バックアップから復元」で移せます。
- **複数人・複数端末で同じデータを共有する機能はまだありません。** 撮影する人が複数いる場合は、各自が出力したExcelを合わせるか、クラウド保存（Googleドライブ/SharePoint連携）の追加が必要です。
- **紙の原本を捨てる場合は電子帳簿保存法の「スキャナ保存」の要件**（タイムスタンプ又は訂正削除履歴の残るシステム、検索機能など）を満たす必要があります。本アプリはその要件を満たす設計ではありません。原本は**テープで貼らずに日付順で封筒・箱に保管**し、日々の確認・集計・台帳作成は本アプリで行う運用を推奨します。
- 写真はピントを合わせ、伝票を平らに置いて**縦向きで枠いっぱいに**撮ると精度が上がります。横向きに写った場合は「↻」で回してから「再読取」してください。iPhoneで写真を選べない場合は「設定 → カメラ → フォーマット → 互換性優先」にしてください。

## 構成

```
index.html / styles.css / app.js   画面（PWA。オフラインでも動く）
js/ocr-worker.js  端末内の文字認識（PaddleOCR を onnxruntime-web で実行）
js/net-extract.js 読み取った文字から正味を特定（全重−風袋で検算）
js/db.js          端末内保存（IndexedDB）
js/image.js       写真の縮小・回転・切り抜き
js/ledger.js      集計ロジック（材料入荷・使用量一覧表）
js/export.js      Excel・写真台帳PDF・ZIP・バックアップ
models/           文字認識モデル（PP-OCRv4, Apache-2.0）
vendor/           ExcelJS / jsPDF / JSZip / ONNX Runtime Web
netlify/functions/read-slip.mjs   （任意）有料AI読み取り
```
