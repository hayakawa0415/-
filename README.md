# 納品書管理（スマホ撮影 → AI読み取り → 現場別Excel集計・写真台帳）

納品書・送り状をスマホのカメラで撮影すると、AI（Claude）が日付・伝票番号・品種・正味重量などを読み取ります。
内容を確認して保存すると、現場ごとに集計され、次の3つを出力できます。

| 出力 | 中身 |
|---|---|
| **Excel集計表** | ①現場別・材料別・月別の集計 ②「材料入荷・使用量一覧表」（現在の様式と同じ：1台目〜15台目、台数/搬入量/使用量の日計・累計、残量）③全伝票の明細 |
| **写真台帳PDF** | A4横に3枚ずつ、日付順に並べた伝票写真（今のテープ貼り台帳の置き換え） |
| **写真ZIP＋Excel** | `現場名/年月/日付_No伝票番号_材料_重量.jpg` の名前で整理した写真と、Excelをまとめたもの |

## 使い方

1. **設定** タブで現場（工事件名）を登録する。
2. **撮影** タブで「納品書を撮影」。続けて何枚でも撮れます（まとめて撮った写真を「写真を選ぶ」で複数選んでも可）。
3. AIの読み取り結果が出たら、**黄色の項目**を写真と見比べて直し、「保存」。
   - 工事名から現場を自動で振り分けます。手で直した振り分け・材料名は覚えて、次から自動で直します。
   - 同じ現場・日付・伝票番号の伝票を保存しようとすると警告します（二重登録防止）。
   - 1枚の写真に伝票が複数写っていても、それぞれ別の伝票として読み取ります。
4. **集計・出力** タブで材料ごとの入荷状況を確認し、「使用量」を入力できます（Excelの使用量欄に入ります）。
5. 必要なときに Excel / 写真台帳PDF / 写真ZIP を出力。「共有」でメール・LINE・Googleドライブへ直接送れます。

スマホではブラウザのメニューから **「ホーム画面に追加」** してアプリとして使ってください（データが消えにくくなります）。

## 導入手順（Netlify）

このリポジトリは Netlify にそのままデプロイできます（`netlify.toml` 設定済み）。

1. Anthropic Console（https://console.anthropic.com）で APIキーを発行し、支払い方法を登録する。
2. Netlify のサイト設定 → Environment variables に次を登録して再デプロイする。

| 変数 | 必須 | 内容 |
|---|---|---|
| `ANTHROPIC_API_KEY` | ○ | AnthropicのAPIキー（サーバー側だけで使い、スマホには渡りません） |
| `APP_PASSCODE` | 推奨 | 設定すると、アプリの「設定」で同じパスコードを入れた端末だけがAI読み取りを使えます。未設定だとURLを知る誰でもAPIを使えてしまいます |
| `SLIP_AI_MODEL` | – | 使うモデル。既定は `claude-opus-5` |
| `SLIP_AI_EFFORT` | – | 読み取りの丁寧さ `low` / `medium` / `high`。既定は `medium` |

APIキーが未設定でも、アプリは**手入力モード**で動きます（集計・出力はすべて使えます）。

### 手元で動かす場合

```bash
npm install
npx netlify dev   # http://localhost:8888
```

## 費用の目安

AI読み取りは1枚あたり5〜10円程度です（`claude-opus-5`、画像1枚＋出力で概算 $0.03〜0.06）。
1日10枚 × 月25日 ＝ 250枚で、**月およそ1,500〜2,500円**が目安です。実際の額は Anthropic Console の Usage で確認してください。
費用を下げたい場合は `SLIP_AI_EFFORT=low` にするか、`SLIP_AI_MODEL=claude-sonnet-5` に変更できます（精度は実物の伝票で確認してから）。

## 注意点（必ずお読みください）

- **AIの読み取りは100%ではありません。** 数字1桁の誤りが請求に直結するため、保存前に正味(kg)・日付・伝票番号は写真と見比べてください。自信のない項目は黄色で表示されます。
- **データはその端末のブラウザ内に保存されます。** 機種変更・ブラウザのデータ削除・（iPhoneで長期間開かない場合の）自動削除で消えることがあります。「設定」→「バックアップを保存」を週1回程度行い、Googleドライブ等に置いてください。別の端末へは「バックアップから復元」で移せます。
- **複数人・複数端末で同じデータを共有する機能はまだありません。** 撮影する人が複数いる場合は、各自が出力したExcelを合わせるか、クラウド保存（Googleドライブ/SharePoint連携）の追加が必要です。
- **紙の原本を捨てる場合は電子帳簿保存法の「スキャナ保存」の要件**（タイムスタンプ又は訂正削除履歴の残るシステム、検索機能など）を満たす必要があります。本アプリはその要件を満たす設計ではありません。原本は**テープで貼らずに日付順で封筒・箱に保管**し、日々の確認・集計・台帳作成は本アプリで行う運用を推奨します。
- 写真はピントを合わせ、伝票を平らに置いて枠いっぱいに撮ると精度が上がります。iPhoneで写真を選べない場合は「設定 → カメラ → フォーマット → 互換性優先」にしてください。

## 構成

```
index.html / styles.css / app.js   画面（PWA。オフラインでも画面は開ける）
js/db.js       端末内保存（IndexedDB）
js/image.js    写真の縮小・回転
js/ledger.js   集計ロジック（材料入荷・使用量一覧表）
js/export.js   Excel・写真台帳PDF・ZIP・バックアップ
netlify/functions/read-slip.mjs   AI読み取り（Claude API）
vendor/        ExcelJS / jsPDF / JSZip（オフライン動作のため同梱）
```
